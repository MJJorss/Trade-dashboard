🔒Data & Access
Data is read from the trade-dashboard-data repository by this site's server, so the repository can stay private and no GitHub token is ever kept in the browser. The site is protected by the password set in Cloudflare (DASHBOARD_PASSWORD); each device stays signed in for 30 days.
